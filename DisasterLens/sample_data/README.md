# DisasterLens AI — Sample Data

This directory holds small reference images used for:
- UI demonstration (the app shows these when no real xBD data is available)
- Smoke tests and README screenshots
- Streamlit widget default uploads

## Contents

```
sample_data/
├── pre_disaster_sample.png    # pre-event satellite crop (512×512)
├── post_disaster_sample.png   # post-event satellite crop (512×512)
└── README.md                  # this file
```

## Image Source

The bundled sample images are procedurally generated by
`scripts/generate_sample_data.py` for demonstration only. They do **not** depict real events
or real property damage.

## Obtaining Real xBD Data

To train or evaluate the model on real imagery:

1. Register at [https://xview2.org](https://xview2.org)
2. Download the xBD dataset (≈ 45 GB, split train/hold/tier3)
3. Extract to a local directory, e.g. `C:/data/xBD/`
4. Update `config.yaml`:
   ```yaml
   paths:
     dataset_root: C:/data/xBD
   ```

The dataset includes pre/post imagery and polygon-level building damage
annotations for 19 disaster events worldwide.
